# Timer Intervalli

Timer a intervalli per HIIT, Tabata, EMOM e boxe, pensato per iPhone.

- Preparazione, lavoro, riposo, round, cicli, riposo tra cicli, defaticamento
- Timer illimitati salvati sul telefono
- Guida vocale in italiano, bip 3-2-1, lampeggio e colori per fase
- Pausa, salto avanti/indietro, cronologia allenamenti
- Schermo sempre acceso durante l'allenamento, layout verticale e orizzontale

**Apri:** https://marcopeli84.github.io/timer/

Su iPhone: Safari → Condividi → Aggiungi alla schermata Home.
